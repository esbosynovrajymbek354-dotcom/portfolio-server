# portfolio-server
Student Digital Portfolio: A platform for students and employers
Students can create a portfolio by gathering their projects, certificates, skills, and achievements in one place. They can attach files to their projects and track portfolio engagement—such as profile views, project views, overall activity levels, and the popularity of specific projects—via an analytics page. Employers can access the platform through dedicated accounts to search for students, review their portfolios, download CVs, and send emails. The platform is built using Node.js and HTML/JS.
